Tạo tài liệu mới

Tài liệu trống

Lưu ý: tạo mới sẽ xóa toàn bộ nội dung hiện tại (không thể hoàn tác).

Mở tài liệu

Từ máy tính

Duyệt file (.docx, .html, .txt)

Lưu tài liệu

Lưu về máy

Word Document (.docx) — mặc định, chuẩn OOXML thật
PDF (.pdf)
Trang Web (.html) — mở lại được trong app này
Văn bản thuần (.txt)

Chưa lưu file nào về máy. Nội dung vẫn được tự động lưu tạm trong trình duyệt sau mỗi lần chỉnh sửa — dù không bấm Save, dữ liệu vẫn không mất khi đóng/mở lại trang.

In tài liệu

In / Xuất PDF

Trình duyệt sẽ mở hộp thoại in — chọn "Lưu dưới dạng PDF" (Save as PDF) làm máy in để xuất file PDF.
